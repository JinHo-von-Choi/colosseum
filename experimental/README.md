# Experimental workflows

[한국어](#실험-워크플로)

These workflows are not loaded by the plugin and are not maintained.

| File | What it did |
|------|-------------|
| `workflows/diagnose.js` | Competing hypotheses, an evidence-consistency matrix and pooled probabilities |
| `workflows/ideate.js` | Silent idea generation, merge, blind ranking and a Borda count |

Each file carries its own copy of the shared library as of Colosseum 1.0.0. To try one, copy it into the plugin's `workflows/` directory and run it as `colosseum:diagnose` or `colosseum:ideate`.

## 실험 워크플로

이 워크플로들은 플러그인이 읽어 들이지 않으며, 유지보수하지 않는다.

| 파일 | 하던 일 |
|------|--------|
| `workflows/diagnose.js` | 경쟁 가설, 근거 일관성 행렬, 확률 풀링 |
| `workflows/ideate.js` | 각자 아이디어 생성, 병합, 블라인드 순위, Borda 집계 |

각 파일에는 Colosseum 1.0.0 시점의 공용 라이브러리 사본이 들어 있다. 써 보려면 플러그인의 `workflows/` 디렉터리로 복사하고 `colosseum:diagnose`나 `colosseum:ideate`로 실행한다.
