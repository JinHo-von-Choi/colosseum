# 출력 형식

## 최종 보고서

```
=== COLOSSEUM ===

질문: [QUESTION]
기준 시점: [AS_OF]
명단: [익명 라벨 A/B/C와 모델 계열] | [이질 명단 / 동종 명단]
진행: [N/3 라운드] | 종료 사유: [해소 / 안정 / 상한 / 토론 불필요]

## 초기 팩트 베이스
[핵심 인용과 대조 결과]

## 기준선
- 블라인드 초안 입장: A [요지] / B [요지] / C [요지]
- BASELINE_VOTE: [입장] (계열 가중)
- P0: [값]

## 라운드별 전개
| 라운드 | 쟁점 | 역할 (검사/변호인/반대증인) | 검증 결과 (v/n/u) | 인정 / 동조 플립 |
|--------|------|---------------------------|-------------------|----------------|

## 충돌 판정
| 쟁점 | A 주장 | B 주장 | 검증된 근거 | 판정 (두 순서) |
|------|-------|-------|-----------|--------------|

## 반대 입장의 가장 강한 논거
[최종 답과 다른 입장을 가장 설득력 있게 정리. 초안의 STRONGEST_COUNTER, 반대자와 사전부검 결과에서 가져오고, 검증 수준을 표시]

## 합의 도달 사항
- ...

## 해소되지 않은 쟁점 (조건부 답변)
- [조건 X일 때]: ...
- [조건 Y일 때]: ...

## 최종 답변
[결론. 팩트 클레임마다 [F번호] 또는 URL을 붙인다] | 기준선 대비: [일치 / 기준선 역전(근거 증거 ID)]
P_final: [값] (UNCALIBRATED)

## 출처
- [F1] URL | 발행처 | 대조 결과(v/n/스니펫/u)
- ...

## 증거 품질 점검표
- 검증률: 판정 클레임 N/N, 보조 클레임 N/N
- 출처 품질: high N / medium N / low N
- 교차 확인: [클레임별 독립 원출처 수]
- 미확인 인용(u): [목록]

## 메타 정보
- 검색: N/25 | 페이지 가져오기: N/15
- 동조 플립: N | 무효 처리된 공격(스틸맨 왜곡): N
- 배심원: [모델 계열] | 순서 민감 판정: N
- 사전부검: [요지] → [반영 / 기각(사유)]
- 제외된 참가자: [없음 / 라벨과 사유]
- 이 답이 틀릴 수 있는 조건: [신호 지표]
```

## 진행 중 투명성 출력

```
[Phase 0] TYPE: N | STAKES: N | 명단: N명 (CLI N, 서브에이전트 N, 이질/동종)
[Phase 1] 검색 N회 | FACT_BASE N개 | 인용 v/n/u N/N/N
[Phase 2] 블라인드 초안 N개 | 인용 v/n/u N/N/N
[Phase 2a] BASELINE_VOTE: [입장] | P0: N | 토론: [진행 / 생략(사유)]
[Phase 2b] 쟁점 C0 = N (경험적 N, 가치 N)
[Round 1] 쟁점 #N | 검사 A, 변호인 B, 반대증인 C
  → 스틸맨: [충실/왜곡] | 공격 인용: [v/n/u] | 응답: [인정/반박/부분 인정]
  → 미해소 N | 인정 N | 동조 플립 N | 판정: [다음 라운드/해소/안정/상한]
[Phase 4] 배심원: [계열] | 두 순서 일치: N/N | 역전: [없음/있음]
  → 사전부검: [반영/기각] | P0 → P_final: N → N
```
